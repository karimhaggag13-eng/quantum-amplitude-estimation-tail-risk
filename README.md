# quantum-amplitude-estimation-tail-risk
BTC/ETH tail-risk analysis using Gaussian and t-copulas, VaR/CVaR, classical Monte Carlo, simulated QAE and IBM hardware with ZNE. To run on IBM, enter in Spyder's IPython console: `from qiskit_ibm_runtime import QiskitRuntimeService; QiskitRuntimeService.save_account(token="YOUR_IBM_CLOUD_API_KEY")`.
